最近刷到了这样的推文：

<blockquote class="twitter-tweet"><p lang="zh" dir="ltr">推特上能找实习吗，我真是没招了</p>&mdash; liz (@siiiipk) <a href="https://twitter.com/siiiipk/status/2030314936795361514?ref_src=twsrc%5Etfw">March 7, 2026</a></blockquote> <script async src="https://platform.twitter.com/widgets.js" charset="utf-8"></script>

作为一个真的尝试过在 X (Twitter) 上找 IT 工作的人，我的答案是：**靠谱，但也绝非易事。**

在推特上找工作确实可以提升自己的存在感（特别是有大家能上手体验的小作品），但是因为信息不对称等原因，无效沟通也特别多。

当然也会有大量嘲讽的声音，以及纯粹蹭热度的评论。

而对于想要把自己内推资格用掉的社畜来说，也未必是最佳渠道。

我们经常能看到圈内大佬公开求职，他们通常知名度高、技术过硬，且拥有坚实的关系网。在我的内推被接受之前，他们的 offer 恐怕早就尘埃落定好了。

而在求职推文或回复区里，还有不少蹭流量的人。例如我表示「可以考虑我司」，往往会引来一堆我完全不了解（甚至连像样的 GitHub 仓库都拿不出来）的人私信求内推。

这种情况对于不太擅长拒绝人的我来说，难以应对（不过绝大部分还是被我拒绝了）。

结论呢？无论是想找工作，还是想消耗内推名额，X 都**值得一试**。它并不是什么高风险的操作，但也请不要抱有太高的期望。

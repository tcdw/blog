谁不希望自己网站的模板漂亮一些呢？
但矛盾的是，漂亮的模板很多都已经烂大街了，少数没有烂大街的又漂亮的模板却没有发布；没有烂大街的模板又恰恰不是喜欢的。
为了解决这个矛盾，我决定重拾网页制作的旧业，同时学习 Typecho 模板制作。

## 编写思路

我在去年下旬尝试编写过模板，但是以失败告终。究其原因，是因为想起来什么就写什么，没有一个完整的思路。

我的主意是首先要考虑好最基本的 CSS 样式，然后设计框架，最后填充样式。

然后把皮套入代码，从而达到制作模板的目的。

## 原则

1. 要保证在多种现代浏览器中显示正常，即使它们的标准互不一致。
2. 要保证良好的用户体验，并尽量减少动画特效。
3. 能不要的东西就抛弃，比如一些小图标可以通过 CSS + Font 方式实现。
4. 考虑不同地区用户的使用体验。
